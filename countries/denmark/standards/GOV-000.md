# GOV-000: Keep Facts and Satire Separate

**Status:** Active for the initial release  
**Category:** Content integrity

## Requirement

Historical claims MUST be presented separately from fictional dialogue, commit messages, diagnostics, and implementation details. A factual incident MUST include at least one source that supports its historical summary.

Satirical text MUST NOT be presented as a real quotation or as evidence for the historical account.

## Rationale

The project uses software metaphors to make history approachable. Clear boundaries let readers enjoy the joke while checking the underlying facts.

## Satirical implementation note

The distinction is mandatory. Its enforcement committee is still being appointed.
