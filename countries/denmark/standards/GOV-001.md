# GOV-001: Engineering & Code Quality

Revision: 1.0  
Status: Adopted for the fictional administration  
Review: Maintainer review through a normal pull request

## Purpose

Technical quality is mandatory. Usefulness is subject to a separate procurement exercise.

## Requirements

Actual compilation, content validation, and test failures MUST fail CI. A successful build MUST NOT be represented as evidence of successful governance.

## Verification

Run dotnet test and inspect the technical pipeline status.

## Interpretation

Government behavior described here is fictional. Engineering and historical-integrity requirements govern the real project. Amendment requires a revised document and ordinary code review.
