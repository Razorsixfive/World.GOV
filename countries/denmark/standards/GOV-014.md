# GOV-014: Report Actual Build Status

**Status:** Active  
**Category:** Operational transparency

## Requirement

Build reports MUST reflect the actual result of the technical build step. Satirical government-domain diagnostics MUST be shown in a separate field and MUST NOT change the build result.

## Rationale

The engineering joke only works if the build is honest. Domain failures may be dramatic; compiler failures remain real.

## Satirical implementation note

The dashboard reports the pipeline it observed. Responsibility for the pipeline remains subject to committee review.
