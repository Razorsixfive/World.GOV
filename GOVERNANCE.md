# Project governance

The repository owner maintains the shared contracts and Denmark reference collection. Country contributors propose data and optional C# modules through pull requests. Ownership of a country name does not grant authority over its historical interpretation.

The maintainer approves changes after CI and source review, documents disagreements, and may defer a contribution that cannot yet be supported. Changes to schemas, public routes, or country contracts require an architecture note and a migration plan when incompatible. Moderation follows CODE_OF_CONDUCT.md; historical corrections follow docs/editorial-policy.md.

Contributors retain copyright in their contributions and submit original contributions under the repository's MIT license. Include required attribution for any permitted third-party material; linked sources retain their own rights. There is no automatic acceptance or promised response deadline. Additional maintainers can be appointed by the owner after a record of constructive review.

Keep maintenance sustainable: small independent entries, no mandatory content cadence, and no commitment to exhaustive national histories. Publish from reviewed main-branch code. Configure branch protection and required CI when creating the GitHub repository.
